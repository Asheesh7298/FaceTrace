FaceTrace

A face → who they are → their real profile → a tamper-proof record on a blockchain.

How it works — 3 stages

📷 face photo in
Stage 1
Detect & encode
MTCNN finds the face → SHA-256 fingerprint + face embeddings.
→
Stage 2
Identify & search
Lens + AWS + local index name the person, then find their real profile.
→
Stage 3
Blockchain
Hash the finding → anchor on-chain → re-verify + tamper test.
verified, tamper-evident record out

The one thing that makes it accurate

🛡️ Verify-before-claim. Before showing any name, FaceTrace downloads real reference photos of that person and re-matches them against the input. It claims an identity only if the faces actually match — so it never shows a wrong person. A guess it can't confirm is shown as "not confirmed", never as a fake result.
