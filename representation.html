1The idea

What it does

You give it a face photo. It figures out who the person is, proves the identity is real, finds their actual profile on the web, and writes a cryptographic hash of that finding onto a blockchain — so the record can never be silently changed.

🧠Identify

Several independent engines figure out who the face is — in parallel.

🛡️Verify

Verify-before-claim re-matches against reference photos, so it never claims a wrong identity.

🔎Find

Search the web for the person's real profile — LinkedIn, Instagram, GitHub, Devfolio.

⛓️Prove

Anchor a SHA-256 of the finding on Ethereum, then re-verify and tamper-test it.

2The pipeline

Three stages

Stage 2 runs every identity engine in parallel, pools a vote, and only claims what it can verify.

📷 Input — a face photo
JPG · PNG · WebP · AVIF · HEIC (auto-normalized)
Stage 1
Detect & encode
MTCNN finds and aligns the face → SHA-256 face hash → ArcFace + FaceNet512 + VGG-Face embeddings.
Stage 2
Identify & search
Engines run at once and vote on the name → verify-before-claim → find the real profile (profiles rank above posts).
Stage 3
Anchor on-chain
Hash the whole finding (SHA-256) → store in the FaceProof contract → read it back to confirm.
✅ Verified, tamper-evident record
re-verify anytime · alter one byte → hash vanishes from the ledger
3The key idea

Verify-before-claim

Reverse-image search is full of look-alikes, so FaceTrace never trusts a raw match — it proves the identity first.

A candidate name is proposed

by Google Lens, AWS Rekognition, or the local index — a hypothesis, not a claim.

Download independent reference photos

several official photos of that person are fetched from the web.

Face-match each one against the input

DeepFace.verify (ArcFace) — the name is claimed only if multiple references agree.

No agreement → honest "not confirmed"

a wrong guess is never shown as a false identity — the demo can't be fooled.

4Coverage

The engines run in parallel

More independent signals = more faces identified; agreement between engines = high confidence.

5The proof

The blockchain record

What goes on-chain is a SHA-256 of a self-describing payload: who was identified, how it was verified, confidence, the source profile, and the hash of the matched image.

📜Anchor

The FaceProof contract stores one immutable record per hash.

🔁Re-verify

Read it back, confirm the stored hash equals the fresh one.

🧪Tamper test

Change one field → its hash is absent from the ledger.

Runs on Hardhat local (instant demo) or Ethereum Sepolia (public) — contract 0x56584844…7e6a3e.
